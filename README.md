## Overview

**Buckshot** is a turn-based shotgun-roulette game. Two players (or a player vs. a bot) take turns firing a shotgun loaded with a mix of **live** and **blank** shells. Survive long enough and outlast your opponent.

The game supports **single-player vs. bots** and **LAN multiplayer**, with a dedicated server mode for hosting matches.

---

## Features

- Single-player matches against bots.
- LAN multiplayer with room creation and joining.
- Turn-based shotgun roulette using live and blank shells.
- Usable items that reveal, modify, or eject shells and affect players.
- Spanish and English language support.
- Synthesized sound effects and a graphical interface.
- Dedicated server mode.
